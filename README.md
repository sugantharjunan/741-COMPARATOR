# Circuit Description

The circuit uses the **LM741 operational amplifier** in comparator mode.

An NTC thermistor changes resistance based on temperature. The op-amp compares the thermistor voltage with a reference voltage generated by resistor dividers.

When the input voltage crosses the threshold:

* The comparator output changes state
* The LED turns ON or OFF

---

# Working Principle

1. The NTC thermistor senses temperature changes.
2. Resistance of the thermistor varies with temperature.
3. Voltage divider generates varying input voltage.
4. LM741 compares:

   * Reference voltage
   * Sensor voltage
5. Output changes depending on comparison result.
6. LED indicates comparator output status.
